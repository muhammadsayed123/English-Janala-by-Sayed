# English Janala

An interactive educational web application designed to help users expand their English vocabulary through structured, step-by-step learning.

## Features
- **Interactive Lessons:** Easily navigate through various levels of English vocabulary.
- **Audio Pronunciation:** Listen to the correct pronunciation of words using the Web Speech API.
- **Detailed Insights:** Access definitions and contextual sentence examples for every word.
- **Modern UI:** Built with Tailwind CSS and DaisyUI for a responsive and clean user experience.

## Technologies Used
- HTML5
- Tailwind CSS
- DaisyUI
- JavaScript (Fetch API)

## How to Run
1. Clone or download this repository to your local machine.
2. Open the `index.html` file in your preferred web browser.
3. Ensure you have an active internet connection to fetch the lesson data from the API.
